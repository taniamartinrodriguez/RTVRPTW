# RTVRPTW — portal de documentación técnica

Proyecto académico de optimización de rutas turísticas con ventanas temporales, basado en el código original ExpositoTOP.

Esta documentación ha sido preparada con ayuda de un LLM y debe ser validada por el estudiante frente a la ejecución real.

**Secciones:** instalación, arquitectura, Maven, calidad, registro de decisiones y documentación API.
